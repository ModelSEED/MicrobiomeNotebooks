# KBase app tool versions vs the latest upstream releases (checked 2026-11-05)

Compiled by a workflow. Three agents worked by tool family, reading the version actually installed in each KBase app (catalog release commit, Dockerfile and build log) and the latest upstream release and changelog.
Two verifiers then re-checked every version claim: 83 were verified and 3 corrected in detail. The full rows, with evidence, are in `kbase_vs_upstream_rows.json` and `kbase_vs_upstream_verification.json`.
