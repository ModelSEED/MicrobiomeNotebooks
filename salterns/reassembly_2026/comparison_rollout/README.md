# Salterns MAG sets: original (2020) vs 2026 first pass vs Arm C rollout

Generated by `compare_rollout.py`. One species clustering over all three sets: skani 0.4.0, ANI >= 95 % and aligned fraction >= 50 %, greedy centroids by completeness - 5 x contamination. QC = CheckM2 1.1.0 where the MAG has it (all originals and rollout MAGs; the 776 per-sample first-pass MAGs), else KBase CheckM 1.1.2 (the 548 first-pass co-assembly MAGs). Taxonomy GTDB-Tk 2.8.0 / R232 everywhere.

Not like-for-like by design: the original set is dereplicated across samples, the first pass is KBase-CheckM-selected (>= 50 / < 10) and includes 4 site co-assemblies, and the rollout is CheckM2 + GUNC-filtered per-sample MAGs. Species clusters are the fair unit across sets.

- 2026 first pass (1,324): 557 species clusters.
- Arm C rollout (935 kept): 373 species clusters.
- site co-assemblies, rollout QC (520 kept): 437 species clusters.

**Why the first pass has more species (557) than the rollout (373).** Of the 231 species clusters found only by the first pass, 212 contain only MAGs of the 4 MEGAHIT site co-assemblies, which the rollout did not redo (it replaced the 39 per-sample assemblies only); 41 of those reach KBase-CheckM completeness >= 90. Only 19 involve per-sample MAGs, and 8 of those have a MAG passing the CheckM2 + GUNC KEEP rule. Like for like, the 559 per-sample first-pass MAGs that pass the KEEP rule fall in 252 species clusters, 239 of which have a rollout MAG (544 of the 559 MAGs).
